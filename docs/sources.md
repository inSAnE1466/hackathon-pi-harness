# Sources

Every source behind a decision in this repository. Each row says what it supports and which doc relies on it.
Links were opened on 2026-11-20 unless marked. Legal rows were verified against the official text on 2026-11-21;
[legal verification](legal-verification.md) quotes the paragraph each claim relies on.

Status: **read** means the passage was read and is summarised here; **link** means the link resolves but the
passage still needs reading; **check** means the claim is ours and needs a source.
